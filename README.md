# Tracker BIO

React-приложение для отслеживания привычек: ежедневные и недельные привычки, быстрые отметки, streak, weekly rings, 4-week heatmap, темы и напоминания.

## Запуск

```bash
npm install
npm run dev
```

## Скрипты

- `npm run dev` - локальный сервер разработки
- `npm run build` - production-сборка
- `npm run lint` - проверка ESLint
- `npm run preview` - просмотр production-сборки
